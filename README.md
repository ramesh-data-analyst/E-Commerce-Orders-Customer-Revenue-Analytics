E-Commerce Orders & Customer Revenue Analytics
Project Overview

This project analyzes e-commerce orders, customers, revenue, and profit performance using Power BI, MySQL, and CSV datasets.

The goal of the project is to understand customer purchasing behavior, sales trends, and revenue performance through an interactive dashboard.

Tools Used
Power BI – Dashboard creation and visualization
MySQL – Data analysis using SQL queries
CSV Files – Source datasets for orders and customers
Files Included
